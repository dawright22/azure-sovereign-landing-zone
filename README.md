# azure-sovereign-landing-zone

A [Git-Ape](https://github.com/Azure/git-ape) community skill that assesses a deployment against the Microsoft [Sovereign Landing Zone (SLZ)](https://learn.microsoft.com/azure/azure-sovereign-clouds/public/overview-sovereign-landing-zone) Sovereignty Baseline control objectives SO-1 to SO-5.

It produces an evidence-based, scope-bound alignment report and a gate result. It is **not** a legal or regulatory certification.

## Contents

* `skills/azure-sovereign-landing-zone/SKILL.md` - the skill
* `skills/azure-sovereign-landing-zone/references/slz-control-catalog.md` - control catalog

## Install

Copy `skills/azure-sovereign-landing-zone` to `.github/skills/community/` in your Git-Ape repository, or open a PR against `Azure/git-ape` as described in its `CONTRIBUTING.md`.
